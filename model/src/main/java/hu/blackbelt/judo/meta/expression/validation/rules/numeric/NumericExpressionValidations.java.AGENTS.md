# `NumericExpressionValidations.java`

Zeta validation rules for `NumericExpression` AST nodes.
Exports `resolved()`, `attributeTypeIsInteger()`, `attributeTypeIsDecimal()`, `integerArithmeticExpressionIsRecommended()`, `integerAggregatedExpressionResolved()`, `decimalAggregatedExpressionResolved()`, `integerSwitchDefaultIsNumeric()`, `decimalSwitchDefaultIsNumeric()`, `integerSwitchCasesAreNumeric()`, `decimalSwitchCasesAreNumeric()`.
Requires `ExpressionValidationContext` with `ModelAdapter`.
