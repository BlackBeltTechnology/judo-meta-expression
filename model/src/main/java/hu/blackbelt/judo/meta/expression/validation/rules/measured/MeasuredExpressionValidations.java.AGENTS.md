# `MeasuredExpressionValidations.java`

Zeta validation rules for `NumericExpression` AST nodes with units/measures.
Exports `measuredDecimalMeasureIsValid()`, `measuredDecimalEnvVarMeasureIsValid()`, `integerAttributeMeasureIsValid()`, `decimalAttributeMeasureIsValid()`, `integerArithmeticMeasureIsValid()`, `integerAdditionMeasureIsValid()`, `decimalArithmeticMeasureIsValid()`, `decimalAdditionMeasureIsValid()`, `integerComparisonIsMeasured()`, `integerComparisonMeasuresMatch()`, `decimalComparisonIsMeasured()`, `decimalComparisonMeasuresMatch()`.
Requires `ExpressionValidationContext` with `ModelAdapter`.
