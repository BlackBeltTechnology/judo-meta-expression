# `model/src/main/java/hu/blackbelt/judo/meta/expression/runtime` — expression model validation runtime

| File | Purpose |
|---|---|
| `ExpressionEpsilonValidatorExecutor.java` | Runs the `expression.evl` suite over the expression model through Epsilon. Implements `ExpressionValidatorExecutor`; `execute` injects `evaluator` and `modelAdapter` and registers wrapped EMF models named `adaptedName`, `MEASURES`, `EXPR`. `setSource(...)` must run first; `EvlScriptExecutionException` is re-thrown as `ExpressionValidationException`. |
| `ExpressionEvaluator.java` | Indexes an expression tree so validation rules can query it. `init(Collection<Expression>)` fills `lambdaContainers`, `referenceSources`, `leaves`; exports `getAllInstances`, `isLambdaFunction`, `isLeaf`, `getExpressionTerms`, `getVariablesOfScope`, `getBase`, `cleanup`. Queries before `init` return empty; a non-`ReferenceExpression` variable source throws `IllegalStateException`. |
| `ExpressionScriptUriProvider.java` | Locates the packaged `validations/` script directory from the `ExpressionModel` code-source location. Exports static `calculateExpressionValidationScriptURI()`, rewriting a `.jar` location to `jar:<loc>!/validations/` and a `jar:bundle:` OSGi location to `bundle://…/validations/`. Abstract, never instantiated. |
| `ExpressionUtils.java` | Reflective bean-property reader plus `ResourceSet` streaming for the Java validation path. Exports static `getValue(value, name)` over a Guava `METHOD_CACHE` (10000 entries, 10s access expiry), `asStream(Iterator, parallel)`, `all()` / `all(Class)`, `setFailOnError`. `getValue` throws `IllegalArgumentException` on null value or missing read property; `all()` needs the `ResourceSet` constructor. |
| `ExpressionValidationException.java` | Checked failure signalling unsatisfied expression constraints. Extends `Exception` with `(message)` and `(message, cause)` constructors; the message is the report produced by `ExpressionValidator.format`. |
| `ExpressionValidator.java` | Reconciles expected against unsatisfied diagnostics. Exports static `format`, `validate`, `validateExpressionInJava`, `validateExpression`. Without expectations only unsatisfied errors fail; with them, unexpected or missing errors fail while unexpected warnings are logged. `validateExpression` resolves the executor reflectively, falling back to `validateExpressionInJava`. |
| `ExpressionValidatorExecutor.java` | Backend contract for running expression validation. Declares `setSource(Logger, ExpressionModel, ModelAdapter, String adaptedName, Resource adapted, String measuresName, Resource measure)` and `execute(Collection<String>, Collection<String>) throws ExpressionValidationException`. Implementations are built by no-arg constructor, so `setSource` must precede `execute`. |
| `ReflectiveExpressionValidatorFactory.java` | Loads a validator implementation by class name so the Epsilon dependency stays optional under OSGi. Exports `createExecutor(className, fallback)` and nested `@FunctionalInterface ValidatorRunnable`. Missing class yields a `Proxy` whose `execute` runs `fallback`; other failures wrap in `RuntimeException`; a class not implementing `ExpressionValidatorExecutor` raises `IllegalArgumentException`. |
