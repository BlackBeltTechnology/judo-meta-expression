# `ObjectExpressionValidations.java`

Zeta validation rules for `ObjectExpression` AST nodes.
Exports `resolved()`, `objectNavigationResolved()`, `objectNavigationTargetIsNotCollection()`, `objectSelectorResolved()`, `objectSelectorOperatorIsValid()`, `objectFilterResolved()`, `objectVariableReferenceResolved()`, `objectVariableReferenceTypeIsDefined()`, `castObjectResolved()`, `castedTypeIsCompatible()`, `containerExpressionResolved()`.
Requires `ExpressionValidationContext` with `ModelAdapter`.
