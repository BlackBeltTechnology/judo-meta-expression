# `builder-jql/src/main/java/hu/blackbelt/judo/meta/expression/builder/jql` — model-agnostic JQL→expression builder core: parse, transform, bind, cache

| File | Purpose |
|---|---|
| `AdaptableJqlExtractor.java` | Generic `JqlExtractor` driver over any `ModelAdapter`, idempotent via binding-existence skip → see `AdaptableJqlExtractor.java.AGENTS.md` |
| `CircularReferenceException.java` | Signals a derived accessor re-entered while its own resolution is still on the stack; message is `"Already resolved accessor: " + accessorName`. Exports `getAccessorName()`. Unchecked — the guard is `JqlExpressionBuildingContext.containsAccessor`, so callers that never push the accessor never get this protection. |
| `CreateExpressionArguments.java` | Immutable argument bag for `JqlExpressionBuilder.createExpression`, built only via `CreateExpressionArgumentsBuilder.withX(...)` → see `CreateExpressionArguments.java.AGENTS.md` |
| `ExpressionBuildingVariableResolver.java` | Mutable stack-state contract for one JQL build (`pushAccessor`/`popVariableScope`…), every push matched by a pop → see `ExpressionBuildingVariableResolver.java.AGENTS.md` |
| `ExpressionMeasureProvider.java` | Measure-name lookup seam handed to temporal and measured transformers: `getMeasureName(String)`, `getDurationMeasureName(QualifiedName)`, `getDurationMeasures()`, `getDefaultDurationMeasure()`. The default-duration result is `Optional`, so a transformer must cope with a model that declares zero or several duration measures. |
| `ExpressionTransformer.java` | One-method seam `transform(JqlExpression, ExpressionBuildingVariableResolver) → Expression` — every JQL AST node reaches the expression metamodel through it. Implemented by `JqlTransformers`; the resolver argument is mutated in place by the callee. |
| `IncompatibleInputParameterException.java` | Signals a derived feature whose declared parameter type does not accept the supplied input parameter; message names both the accessor and the input parameter. Exports `getAccessorName()` (the input parameter name is folded into the message only). Unchecked. |
| `JqlExpressionBuildException.java` | Carries a `List<JqlExpressionBuildingError>` plus the `partialExpression` produced before the failure, so a caller can still inspect what was built. Message concatenates each error's `getDescription()`. Exports `getErrors()`, `getPartialExpression()`, `getJclObject()` — both constructors leave `jclObject` null, so read the per-error `getJclObject()` instead. |
| `JqlExpressionBuilder.java` | Central JQL→expression facade: parse, build, store, bind, and resolve type/measure names. → see `JqlExpressionBuilder.java.AGENTS.md` |
| `JqlExpressionBuilderConfig.java` | Holds the single build-time switch `resolveOnlyCurrentLambdaScope` (default `true`) with getter/setter. `JqlExpressionBuildingContext` reads it on every `resolveVariable`, `getVariables` and `removeVariable`, so flipping it mid-build changes name resolution for the remainder of that build. |
| `JqlExpressionBuilderModelAdapterCache.java` | Per-`ModelAdapter` prebuilt `Instance`/`TypeName`/`MeasureName` maps; `getCache(ModelAdapter)` sole entry point, Guava `LoadingCache` expiry 86400s → see `JqlExpressionBuilderModelAdapterCache.java.AGENTS.md` |
| `JqlExpressionBuildingContext.java` | `ExpressionBuildingVariableResolver` backed by `ArrayDeque`s: a stack of lambda variable scopes plus accessor, base and base-expression stacks. Constructors push one initial variable scope, so `popVariableScope()` must never outnumber pushes. `resolveVariable` matches `humanName` falling back to `name`. `pushBase(null)` is silently ignored; `getVariables()` returns an unmodifiable copy. |
| `JqlExpressionBuildingError.java` | Value pair of an error `description` and the offending `EObject jclObject`; `toString()` joins them with a space. Produced by function and node transformers, collected into `JqlExpressionBuildException`. |
| `JqlExtractor.java` | Extraction contract implemented per metamodel: `extractExpressions()` returns the populated expression `ResourceSet`, and `JQL_DIALECT = "JQL"` names the dialect of the strings it reads. Implementations must extract only expressions that have no binding yet, so repeated runs stay additive. |
| `JqlTransformerUtils.java` | Static `castExpression(Class<T>, Supplier)` and `validateParameterCount(functionName, ...)` argument guards shared by function transformers → see `JqlTransformerUtils.java.AGENTS.md` |
| `JqlTransformers.java` | Registry that maps every JQL node class and every JQL function name to its transformer. → see `JqlTransformers.java.AGENTS.md` |
| `PartialExpression.java` | Pairs an `Expression` that may be incompletely built after a parse failure with the `JqlExpressionBuildingContext<TO>` active at that point, both read-only via `getExpression()` / `getContext()`. The context is handed out live, so its stacks still reflect the aborted build. |
